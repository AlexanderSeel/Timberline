# Design loop and tuning
- Follow `docs/GAME_DESIGN.md`: explore → harvest → craft → build → inhabit → grow → exchange.
- Make each unlock visible and useful. Avoid grind, arbitrary energy gates, forced PvP and manipulative timers.
- Balance ecology, resources, seasons, NPC needs and task economics; player decisions should have predictable consequences.
- Make a shelter achievable in ~20 min and gardening/interaction within first hour, then test and tune based on real play.
- Single-player offline must be fun before opt-in co-op. Implement ownership, privacy and moderation before social rollout.
- Write acceptance scenarios and metrics, not just empty feature names.
