# Cost-conscious AI asset workflow
- Prefer Poly Haven and ambientCG CC0 scanned materials; use Blender locally for authored geometry.
- Use image generation only via tools demonstrably installed and authorized, for mood/concept/reference/decals. ChatGPT Plus is not API credit.
- Tripo Studio balance is *not* Tripo API balance. Reported ~700 Studio credits are not programmatically spendable through Tripo API.
- For each **paid** generation, propose one hero asset, preview cost and permission; do not click generate, retry or bulk purchase without explicit approval.
- After download, record cost/rights, retopo in Blender and test GLB in game. Reject poor topology, texture drift or unusable cut-outs.
- Maintain `assets/asset-manifest.json` with provenance, license and source URLs.
